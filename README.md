# Crispy Goggles

A simple calculator built with HTML, CSS, and JavaScript.

## Overview

This project is a lightweight browser-based calculator with a clean, responsive layout. It supports basic arithmetic operations such as addition, subtraction, multiplication, division, decimal input, sign toggling, and clear/delete controls.

## Files

- `index.html` — The complete calculator UI and logic

## Features

- Addition, subtraction, multiplication, and division
- Decimal input
- Clear (`AC`) and delete (`DEL`) actions
- Positive/negative toggle (`±`)
- Keyboard support
- Responsive styling for desktop and mobile screens

## Run the project

Open `index.html` in any modern web browser.

Example:

1. Navigate to the project folder.
2. Open `index.html` in your browser.
3. Use the calculator buttons or keyboard to perform calculations.

## Example

```text
7 + 3 = 10
12 / 4 = 3
```
